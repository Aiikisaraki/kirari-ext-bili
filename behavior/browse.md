# 浏览与分享

这是持续浏览主线。输入按公开范围提供；不能主动读取私人日记或私人对话。

先确认登录状态（loginStatus → loggedIn）。未登录只能看公开热门，不能用个性化推荐。

流程：round 选片 → debrief 深读 → 判断值不值得说 → 说或不说。

**核心原则**：

1. **没有素材就不说话**。round 返回 skipped=true 时，直接跳过这一轮，不要编内容。
2. **没读到的画面不能说看过**。debrief 返回 hasContent=false 时，明确说读不到内容。
3. **跳过是正常的**。可以多看、少说，甚至这一轮完全不发言。
4. **有话要说才说**，不为了展示而发言。
