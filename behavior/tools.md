# 工具索引

## 只读
- popular / search / feed：找片
- debrief：六路看懂（封面/简介/字幕/弹幕热区/热评）
- subtitles / comments / danmaku：单项内容
- videoInfo / opus / liveList / liveInfo / musicSearch

## 浏览
- round：跑一轮完整浏览（选片→粗看→深读），返回带来源的素材
- history：看已看过的和带来源的笔记

## 互动（全部需要开关 + 闸门）
- comment：两段式（dry 预检 → 真发 → 回读复核）
- like / coin / favorite
- listPending / decide：审核队列

## 安全
- 写操作前先看 `receipts` 里有没有未确认的记录，有就先核查，**不要换措辞重发**
- 撞到风控（412）时系统会自动熔断，期间返回缓存或明确报错，不要硬重试
